# XPT2046 (resistive)

A 12-bit touch ADC on SPI. Source: OWLOS Flight Radar `firmware/main/touch.c` (the XPT2046 half), the Air Quality
UI's touch.c. Sureness words as in [SKILL.md](../../SKILL.md). The raw numbers go through the alignment:
[touch-alignment](../touch-alignment.md).

## Where it is, and how it is wired

- **Bit-banged on its own pins** (`TOUCH_XPT_BITBANG`): the 2.8" CYD [measured], the ZLX-ESP32-2 [built]. Cheap,
  and the LCD bus stays free. On the CYD two of its pins are input-only GPIOs (36, 39).
- **On the LCD bus** (`TOUCH_XPT_SPI`): the 3.5" CYD R version, CS 33 [measured]; the NM-CYD-C5, CS 1 [built]; the
  Air Quality board, CS 17 [measured there]. A second device on SPI2 at 2 MHz, `spi_device_polling_transmit`, 24
  bits; the driver changes the clock per device.
- FusionEdge (LovyanGFX's `Touch_XPT2046`): on the CYD on its own SPI host at 1 MHz; on the E32R35T on the
  panel's bus, read through MISO 12, 1 MHz; default 2.5 MHz; and the raw range of the panel's corners as
  `TS_X_MIN`..`TS_Y_MAX` [docs; the E32R35T's touch measured there].
- The ZLX-ESP32-2's maker test: 2 MHz, X and Y swapped, raw 220 to 3880 both ways [docs]. The alignment finds the
  axes anyway.
- Pins: the board files ([ili9341](../../../esp32-boards/references/boards/ili9341.md),
  [st7796](../../../esp32-boards/references/boards/st7796.md),
  [nmcydc5](../../../esp32-boards/references/boards/nmcydc5.md),
  [zlx2](../../../esp32-boards/references/boards/zlx2.md)).

## The commands

S A2 A1 A0 MODE SER PD1 PD0 [docs]. 0xD1 X, 0x91 Y, 0xB1 Z1, 0xC1 Z2: 12 bits, differential, ADC on. 0xD0: power
down with the pen interrupt enabled, so every read ends with it. A transfer is the command, then 16 clocks: busy
bit, 12 data bits, 3 zeros, `>> 3`. 0xA7 is VBAT, single ended with the 2.5 V reference on; Air Quality reads it
twice and throws the first away, and there it read 0 V: nothing is wired to it.

## The driver

```c
#if TOUCH_XPT_BITBANG || TOUCH_XPT_SPI
#include "driver/gpio.h"

#define Z_MIN 350            // below this its not a press

static int xfer(uint8_t cmd);
static void chip_select(int on);

/* the pen interrupt: the XPT2046 pulls T_IRQ low while the panel is pressed (in power down with
 * the pen interrupt on, which is how tp_read leaves it). while it is high there is nothing to
 * read. on the 3.5" board that keeps the touch off the LCD's bus: every read there waited for a
 * strip to go out and held the next one back, a third of the frame. a pin that is not wired or
 * lies is found out: it reads low at the start, or a read every 20th sample finds a press it
 * missed. then every sample asks the chip, as before */
static int s_irq;

#ifndef PIN_T_IRQ_PULLUP
#define PIN_T_IRQ_PULLUP 0      // the CYDs pull it up on the board (36 has no pull-up of its own)
#endif

static void irq_init(void)
{
    gpio_config_t in = { .pin_bit_mask = 1ULL << PIN_T_IRQ, .mode = GPIO_MODE_INPUT,
                         .pull_up_en = PIN_T_IRQ_PULLUP ? GPIO_PULLUP_ENABLE : GPIO_PULLUP_DISABLE };
    gpio_config(&in);
    chip_select(1);
    xfer(0xD0);                                      // power down, pen interrupt on
    chip_select(0);
    s_irq = gpio_get_level(PIN_T_IRQ) == 1;
    ESP_LOGI(TAG, "pen interrupt on GPIO %d: %s", PIN_T_IRQ, s_irq ? "the chip is read only while pressed" : "low, every sample asks the chip");
}

#if TOUCH_XPT_BITBANG
#include "esp_rom_sys.h"

void tp_init(void)
{
    gpio_config_t out = {
        .pin_bit_mask = (1ULL << PIN_T_CLK) | (1ULL << PIN_T_MOSI) | (1ULL << PIN_T_CS),
        .mode = GPIO_MODE_OUTPUT,
    };
    gpio_config(&out);
    gpio_config_t in = {
        .pin_bit_mask = (1ULL << PIN_T_MISO) | (1ULL << PIN_T_IRQ),
        .mode = GPIO_MODE_INPUT,
    };
    gpio_config(&in);
    gpio_set_level(PIN_T_CS, 1);
    gpio_set_level(PIN_T_CLK, 0);
    ESP_LOGI(TAG, "XPT2046 on its own pins");
    irq_init();
}

static void chip_select(int on) { gpio_set_level(PIN_T_CS, !on); }

// send command byte, then clock in 16 bits: busy bit, 12 data bits, 3 zeros
static int xfer(uint8_t cmd)
{
    for (int i = 7; i >= 0; i--) {
        gpio_set_level(PIN_T_MOSI, (cmd >> i) & 1);
        esp_rom_delay_us(1);
        gpio_set_level(PIN_T_CLK, 1);
        esp_rom_delay_us(1);
        gpio_set_level(PIN_T_CLK, 0);
    }
    gpio_set_level(PIN_T_MOSI, 0);
    unsigned v = 0;
    for (int i = 0; i < 16; i++) {
        esp_rom_delay_us(1);
        gpio_set_level(PIN_T_CLK, 1);
        esp_rom_delay_us(1);
        v = (v << 1) | (unsigned)gpio_get_level(PIN_T_MISO);
        gpio_set_level(PIN_T_CLK, 0);
    }
    return (int)((v >> 3) & 0xFFF);
}

#else   /* XPT2046 as a second device on the LCD bus (bus is set up by disp_init) */
#include "driver/spi_master.h"
#include "display.h"

static spi_device_handle_t s_dev;

void tp_init(void)
{
#if TOUCH_GT911_TOO
    if (gt_find()) return;
    i2c_bus_free();                                  // nobody there: 33 is the XPT2046's chip select again
#endif
    spi_device_interface_config_t dev = {
        .clock_speed_hz = 2 * 1000 * 1000,       // the XPT2046 wants it slow
        .mode = 0,
        .spics_io_num = PIN_T_CS,
        .queue_size = 1,
    };
    if (spi_bus_add_device(SPI2_HOST, &dev, &s_dev) != ESP_OK) ESP_LOGE(TAG, "XPT2046 not added to the bus");
    irq_init();
}

static void chip_select(int on) { (void)on; }         // the SPI driver does CS for every transfer

static int xfer(uint8_t cmd)
{
    spi_transaction_t t = { .length = 24, .flags = SPI_TRANS_USE_TXDATA | SPI_TRANS_USE_RXDATA };
    t.tx_data[0] = cmd;
    /* the bus is the screen's too: the strip on its way goes out first, the touch never asks for
     * the bus against it. lcd_spi.c found that waiting in the driver's bus lock can hang */
    disp_wait_idle();
    if (!s_dev || spi_device_polling_transmit(s_dev, &t) != ESP_OK) return 0;
    return (int)(((t.rx_data[1] << 8) | t.rx_data[2]) >> 3) & 0xFFF;
}
#endif

static int median5(int *v)
{
    for (int i = 1; i < 5; i++)
        for (int j = i; j > 0 && v[j - 1] > v[j]; j--) { int t = v[j]; v[j] = v[j - 1]; v[j - 1] = t; }
    return v[2];
}

int tp_read(int *rx, int *ry)
{
#if TOUCH_GT911_TOO
    if (s_gt) return gt_read(rx, ry);
#endif
    static uint32_t n;
    static int was;                                  // the last read of the chip said pressed
    int idle = s_irq && gpio_get_level(PIN_T_IRQ);
    if (idle && !was && ++n % 20) return 0;          // not pressed, says the pin. every 20th, and after a press read: ask anyway
    chip_select(1);
    int z1 = xfer(0xB1), z2 = xfer(0xC1);
    int z = z1 + 4095 - z2;
    int pressed = z1 > 0 && z >= Z_MIN;
    if (pressed) {
        int xs[5], ys[5];
        for (int i = 0; i < 5; i++) xs[i] = xfer(0xD1);
        for (int i = 0; i < 5; i++) ys[i] = xfer(0x91);
        *rx = median5(xs);
        *ry = median5(ys);
        pressed = *rx > 50 && *rx < 4050 && *ry > 50 && *ry < 4050;   // values at the very edge are junk
    }
    xfer(0xD0);                                  // power down, pen interrupt on
    chip_select(0);
    /* a press counts once two reads in a row say it, 15 ms later than one would. one read alone was the chip's
     * noise: now and then after a restart it said a press at the 3.5"'s look button, and the look went one on
     * (four times in a day), or it took the pen interrupt for a liar and slowed every frame from then on */
    const int sure = pressed && was;
    was = pressed;
    if (sure && idle) {
        s_irq = 0;
        ESP_LOGW(TAG, "a press the pen interrupt did not show: every sample asks the chip from now on");
    }
    return sure;
}
#endif
```

## The rules in it

- **Pressure first.** Without the Z check the resistive panel invents taps. `Z_MIN` 350, edge limits 50 and
  4050, 5 reads per axis, median [measured on the 2.8", the 3.5" and the Air Quality board].
- **Two reads in a row make a press** (new since the first version of these notes). One noisy read became a
  press, and any press with a release is a tap: after a restart the 3.5" changed its look by itself four times
  in a day, and the same read made the driver distrust its pen interrupt for good, which slowed every frame. A
  PC test with a pretend chip: 191 phantom presses in 400 idle samples before, 0 after, a finger seen 15 ms
  later [measured on the PC; the boards run it since].
- **The pen interrupt keeps the touch off the bus.** Each read on the 3.5" waited for a strip to go out and held
  the next one back: a third of the frame [measured]. T_IRQ is low while pressed if the chip was left with 0xD0.
  High means nothing to read. A pin that reads low at the start is not trusted; one that misses a press (found
  by the read every 20th sample, and the read after any press) is dropped and every sample asks the chip. A dead
  pin costs at most 20 samples, about 0.3 s, once.
- **A pull-up where the board has none**: `PIN_T_IRQ_PULLUP 1` (the ZLX-ESP32-2, as its maker's test does). The
  CYDs pull it up on the board, and GPIO 36 has no pull-up of its own.
- **No pen wire at all** (an ILI9488 asker's wiring): guard `irq_init` and the pin read with `#ifdef PIN_T_IRQ`
  and leave `s_irq` 0. Not in the code yet.
- **On the LCD bus**, `disp_wait_idle()` before every `xfer`. A whole read is 13 transfers. Only the task that
  sends strips may call `tp_read`. Never wait in the driver's bus lock against a strip: that is the hang in
  [bus-spi-strips](../bus-spi-strips.md).
- Air Quality's XPT2046 is the same without the pen check: its `tp_read` calls `disp_wait()` once at the top,
  because the LCD's CS is held down by hand during a strip there and a touch transfer then would talk to both
  ([ili9486](../panels/ili9486.md)).
- **Bit-banged timing**: `esp_rom_delay_us(1)` twice a bit, a clock of 2 us or more, well inside the chip, and
  it never waits for the screen.
- **The 3.5" C version shares the pin**: its GT911 is on SDA 33, SCL 32, while the R version's XPT2046 CS is 33.
  `tp_init` asks for a GT911 first and gives the pins back when nobody answers ([gt911](gt911.md)).
- `TOUCH_RAW_SPAN` 3700 for the sanity check of a stored alignment.
- Nail or stylus works best on resistive; buttons over a map answer 8 to 12 px further out than they are drawn.

## Axes, by board

- 2.8" CYD at MADCTL 0xE8: swapped, both reversed. Screen x falls with raw y, screen y falls with raw x. Corners
  read (3320,3393) (3377,485) (627,401) (618,3384), centre (1980,1955). Default until aligned:
  `{ 0, -0.0894, 333.3, -0.0666, 0, 251.1 }`. Without alignment only the biggest button could be hit
  [measured].
- The 3.5" and the Air Quality panel: same method, no fixed numbers kept.
- The RPi LCD panel bends towards its edges: the affine map left the bottom row 15 to 20 px off, so Air Quality
  fits a 9 point quadratic ([touch-alignment](../touch-alignment.md)).
