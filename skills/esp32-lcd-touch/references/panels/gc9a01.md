# GC9A01

240x240 round SPI panel, through `lcd_spi.c` ([bus-spi-strips](../bus-spi-strips.md)). Sureness words as in
[SKILL.md](../../SKILL.md).

## Where it is

- Elecrow CrowPanel 1.28" round, ESP32-C3 [measured: about 8 fps, 31 KB heap left]. Board file:
  [gc9a01](../../../esp32-boards/references/boards/gc9a01.md).
- Not ported: ESP32-2424S012C (round 1.2", C3, GC9A01 at 80 MHz, BGR, CST816S). Its backlight is a plain GPIO,
  no expander, so it is near the CrowPanel 1.28 without the hard part.

## Settings that work

- MADCTL 0x68 (MV|MX|BGR), from ViewOwl's lcd_gc9a01.c (an earlier firmware of ours); 0x28 came out mirrored
  [measured].
- Pixel format 0x3A 0x05, inversion on (0x21) [measured]. `remind()` re-sends 0x05, read from the table, not
  a global 0x55.
- 80 MHz: the C3's IOMUX pins for SPI2. Snow on the screen would mean go to 40; never seen here.
- Strips of 16 rows, 15 strips: the C3's heap is small.
- 0x35 turns the tearing line on; the pin is not used.
- The C3 has one core at 160 MHz and no floating point unit: the weather look's clouds took half its frame
  until its discs were drawn in whole numbers.
- On round glass nothing may sit in the corners: the touch alignment's crosses go 20 percent in, on the
  diagonals ([touch-alignment](../touch-alignment.md)).

## Reset and backlight on an I2C expander

The round board has the backlight, the LCD reset and the touch reset on a PI4IOE5V6408 at 0x43 (backlight bit
2, touch reset bit 3, LCD reset bit 4). On or off only, so `PIN_LCD_BL` is -1 and there is no dimming. The
expander comes up before the first LCD command; the panel is in reset until then, so this table has no 0x01
and starts from the expander's hardware reset [measured].

```c
/* PI4IOE5V6408 expander: backlight on, LCD and touch out of reset */
static void expander_power_on(void)
{
    i2c_master_dev_handle_t ex = i2c_dev(IOEX_ADDR);
    const uint8_t mask = IOEX_BIT_BL | IOEX_BIT_RST | IOEX_BIT_TRST;   // bits 2, 4, 3
    const uint8_t seq[][2] = {
        { 0x03, mask },                      /* direction: these are outputs */
        { 0x07, (uint8_t)~mask },            /* hi-z off for them */
        { 0x0B, 0x00 },                      /* no pulls */
        { 0x05, IOEX_BIT_BL },               /* resets low, backlight on */
    };
    for (size_t i = 0; i < sizeof seq / sizeof seq[0]; i++)
        if (i2c_master_transmit(ex, seq[i], 2, 100) != ESP_OK) ESP_LOGE(TAG, "expander write %02x failed", seq[i][0]);
    vTaskDelay(pdMS_TO_TICKS(20));
    i2c_master_transmit(ex, (const uint8_t[]){ 0x05, mask }, 2, 100);   /* resets released */
    vTaskDelay(pdMS_TO_TICKS(120));
}
```

The C3's `i2c_master` with the CST816 and this expander has shown no hang [measured]. The touch:
[cst816](../touch/cst816.md).
