# ESP32-S3-DevKitC-1 N16R8 with an ILI9488 module (FusionEdge build `s3-ili9488`)

FusionEdge's primary target, an internet radio: an ESP32-S3 DevKitC-1 (44 pins) wired to a 3.5" ILI9488 SPI module with
capacitive touch, an SD card, a PCM5102A I2S DAC, encoders, an IR receiver and a QCC5124 Bluetooth module.

- Build: FusionEdge's `s3-ili9488` (the root `myoptions.h` and `platformio.ini` of github.com/SimZs/FusionEdge, GPL-3.0).
  No Flight Radar build.
- How sure: docs for this skill (built in FusionEdge's CI, run by FusionEdge's authors, not here). Pins as the
  configuration has them; a wired board can differ.
- Never copy FusionEdge's GPL code into an MIT project; facts and pins are fine.

## Chip, flash, PSRAM

ESP32-S3 N16R8 ([esp32-s3](../chips/esp32-s3.md)): `board = esp32-s3-devkitc1-n16r8`, `memory_type = qio_opi`, flash
QIO, PSRAM octal, 16 MB, `-DBOARD_HAS_PSRAM`, CPU 240 MHz. Partitions `partitions.csv`: two 6 MB OTA app slots, 3.8 MB
LittleFS, a 128 KB core dump (../board-files.md).

## Screen and touch

- ILI9488 (`DSP_MODEL DSP_ILI9488`): DC 10, CS 18, RST none, SCK 12, MOSI 11 (MISO 13 left off), backlight 14 (PWM,
  4.5 kHz default). Panel: ../../../esp32-lcd-touch/references/panels/ili9488.md.
- Touch FT6X36 (`TS_MODEL_FT6X36`): SDA 8, SCL 9, RST 42, INT 41. A resistive XPT2046 on CS 42 is the other option.
  ../../../esp32-lcd-touch/references/touch/ft6336.md.

## Other parts

- SD card CS 39 on the display's SPI pins (SCK 12, MISO 13, MOSI 11) at 4 MHz: slower to keep the shared bus from
  flickering the display.
- PCM5102A DAC: DOUT 38, BCLK 21, LRC 47. MUTE pin 2.
- Encoder: right 4, left 6, button 5, internal pull-ups.
- QCC5124 Bluetooth (AT commands): UART TX 45, RX 46 at 115200, its I2S BCK 7, LRCK 15, DATA 16.
- IR receiver 17, wake pins 1 and 17. LED strip 48 (the S3 board's RGB LED pin).
