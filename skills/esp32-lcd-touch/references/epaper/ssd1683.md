# SSD1683 e-paper: the driver both CrowPanels share

The e-paper controller of the Elecrow CrowPanel 4.2" (one SSD1683) and 5.79" (two in a cascade). Source: OWLOS
Flight Radar `firmware/main/epd.c` (570 lines), the same file in OWLOS WiFi Radar before the 4.2"'s grey work. The
start-up sequences and LUTs come from ViewOwl (an earlier firmware of ours; its 5.79" is a port of Waveshare's
EPD_5in79 and Elecrow's CrowPanel example). Sureness words as in [SKILL.md](../../SKILL.md).

The panel parts: [crowpanel-42](crowpanel-42.md), [crowpanel-579](crowpanel-579.md). What the radar draws on it and
how it decides: [paper-screen](paper-screen.md).

## The model

- 4 greys, 2 bits a pixel. Codes: 3 white, 2 light grey, 1 dark grey, 0 black. 4 pixels a byte, left pixel on
  top, a row padded with white.
- RAM 0x24 gets bit 0 of the code, RAM 0x26 bit 1: white and dark grey are 1 in 0x24, white and light grey 1 in
  0x26. A full refresh with the grey LUT (`0x22 0xCF`, then 0x20) shows all four.
- A partial refresh can only make black or white. The panel gets the new picture in 0x24 and the one on the glass
  in 0x26 and repaints only where they differ, with its own fast waveform (`0x22 0xFF`). A pixel that does not
  flip keeps its grey; one that flips loses it.
- So the driver keeps two frames of codes: `s_frame`, the new picture, and `s_shown`, a model of what really is on
  the glass. 54 KB each on the wide panel, in PSRAM when there is some.
- `count_changes` gives the flips and the **grey debt**: pixels that would show the wrong grey after a partial (a
  grey that came or went where black and white stay the same, or a pixel that flips but should end up grey).
- The strips are packed into `s_frame` as they come (`paper_pack`); `disp_frame_end` is where the glass is touched,
  and it has to be called once a frame.

## The refresh decision

- Full 4-grey refresh: a new screen (`disp_full_next()`), every 10 minutes for ghosts, or a grey debt over 8000
  pixels, but not more often than every 3 minutes for that. It takes seconds and flashes.
- Otherwise, if any pixel flips: a partial on top, black and white, no flash. Then the model is updated: flipped
  pixels are plain black or white now.
- Nothing flips: the glass is not touched at all.
- A new picture is drawn every 5 s (`disp_frame_ms`), but the glass changes only if something in it did.
- The soft edges of changing digits alone make 2000 to 4000 pixels of debt a minute (measured on the 5.79"), and
  they do not matter: they just turn crisp. Grey fills do; they are thousands of pixels.

## The code

```c
/*
 * e-paper, SSD1683, bit-banged SPI, 4 greys. the strips are turned into 2 bit codes
 * (core/paper.c) and collected into a frame, disp_frame_end() puts it on the glass.
 * a full 4-grey refresh (~3 s, it flashes) only for a new screen and every 10 min.
 * in between the changes are drawn on top with a partial refresh: black and white only,
 * no flash, and pixels that didn't change keep their grey. if nothing changed the glass
 * isn't touched at all. that is why ui_paper.c keeps grey to the parts that never change.
 *
 * 4.2" 400x300: one controller. 5.79" 792x272: two controllers in a cascade, master and
 * slave, one CS, the slave answers to the master's opcodes + 0x80.
 * the init, the grey LUTs and the plane packing are ViewOwl's epd_4in2.c / epd_wide.c,
 * which show 4 clean greys on these panels.
 * codes: 3 white, 2 light grey, 1 dark grey, 0 black. RAM 0x24 gets bit 0 of the code,
 * RAM 0x26 bit 1 (white and dark grey -> 1 in 0x24, white and light grey -> 1 in 0x26)
 */
#include "display.h"
#if DISP_EPD

#include <string.h>
#include "paper.h"
#include "driver/gpio.h"
#include "esp_heap_caps.h"
#include "esp_rom_sys.h"
#include "esp_log.h"
#include "esp_task_wdt.h"
#include "esp_timer.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

static const char *TAG = "epd";

#define SPI_DELAY_US    1         // half clock, the panel is happy well under 1 MHz
#define BUSY_TIMEOUT_MS 10000

#define FULL_EVERY_US  (10LL * 60 * 1000000)  // greys repainted and ghosts cleared every 10 min
#define FULL_GAP_US    (3LL * 60 * 1000000)   // but not more often than this for wrong greys
/* this many pixels with a wrong grey -> full refresh. the soft edges of changing digits
 * alone make 2000-4000 a minute (measured on the 5.79"), and those don't matter, they just
 * turn crisp. the grey fills do, they are thousands of pixels */
#define GREY_DEBT_MAX  8000

/* two pictures of 2 bit codes (4 px a byte, left pixel on top): the new one, and a model
 * of what really is on the glass. a partial refresh can only put black or white, so the
 * model knows where greys are missing (the "grey debt"). 54 KB each on the wide panel,
 * they go to PSRAM when the board has it */
static uint8_t *s_frame, *s_shown;
#define FRAME_BYTES (PAPER_STRIDE * GFX_H)
static uint32_t s_lost;
static int      s_full = 1;                       // next refresh is a full grey one
static int64_t  s_last_full;

uint32_t disp_lost(void) { return s_lost; }
void disp_backlight(int percent) { (void)percent; }
void disp_full_next(void) { s_full = 1; }

// a new picture every 5 s, but the glass is only touched if something in it changed
uint32_t disp_frame_ms(void) { return 5000; }

/* --- bit-bang, CS goes up after every byte like in ViewOwl --- */

static void wr_bus(uint8_t d)
{
    gpio_set_level(EPD_PIN_CS, 0);
    for (int i = 0; i < 8; i++) {
        gpio_set_level(EPD_PIN_SCK, 0);
        gpio_set_level(EPD_PIN_MOSI, (d & 0x80) ? 1 : 0);
        esp_rom_delay_us(SPI_DELAY_US);
        gpio_set_level(EPD_PIN_SCK, 1);           // sampled on the rising edge
        esp_rom_delay_us(SPI_DELAY_US);
        d <<= 1;
    }
    gpio_set_level(EPD_PIN_CS, 1);
}

static void wr_cmd(uint8_t c)
{
    gpio_set_level(EPD_PIN_DC, 0);
    wr_bus(c);
    gpio_set_level(EPD_PIN_DC, 1);
}

static void wr_data(uint8_t d)
{
    wr_bus(d);                                    // DC is already high
}

static void wait_busy(void)
{
    int waited = 0;
    while (gpio_get_level(EPD_PIN_BUSY) == 1) {   // high = busy
        vTaskDelay(pdMS_TO_TICKS(10));
        if (esp_task_wdt_status(NULL) == ESP_OK) esp_task_wdt_reset();   // a refresh takes seconds, its not a hang
        waited += 10;
        if (waited >= BUSY_TIMEOUT_MS) {
            ESP_LOGE(TAG, "BUSY stuck high for %d ms, check GPIO%d", waited, EPD_PIN_BUSY);
            s_lost++;
            return;
        }
    }
}

// 2 bit code of pixel x,y of our frame
static inline uint8_t code_at(int x, int y)
{
    if (x >= GFX_W || y >= GFX_H) return 3;
    return (uint8_t)((s_frame[y * PAPER_STRIDE + (x >> 2)] >> (6 - 2 * (x & 3))) & 3);
}

// 8 pixels from x0 on, one bit of their codes each (bit 0 for RAM 0x24, bit 1 for 0x26)
static uint8_t plane8(int x0, int y, int bit, int flip)
{
    uint8_t out = 0;
    for (int k = 0; k < 8; k++) {
        int x = x0 + k;
        uint8_t c = flip ? code_at(GFX_W - 1 - x, GFX_H - 1 - y) : code_at(x, y);
        out = (uint8_t)(out << 1 | ((c >> bit) & 1));
    }
    return out;
}

static inline uint8_t shown_at(int x, int y)
{
    if (x >= GFX_W || y >= GFX_H) return 3;
    return (uint8_t)((s_shown[y * PAPER_STRIDE + (x >> 2)] >> (6 - 2 * (x & 3))) & 3);
}

/* black and white for the partial refresh: white and light grey count as white.
 * the panel gets the new picture and the old one, and repaints only the pixels where the
 * two differ. greys where nothing changed stay */
static inline int bw_new(int x, int y) { return code_at(x, y) >= 2; }
static inline int bw_old(int x, int y) { return shown_at(x, y) >= 2; }

/* what a partial refresh would change (black/white flips), and how many pixels would still
 * show the wrong grey after it: a grey that came or went where black/white stays the same,
 * or a pixel that flips but should end up grey */
static void count_changes(int *flips, int *debt)
{
    int f = 0, d = 0;
    for (int i = 0; i < FRAME_BYTES; i++) {
        uint8_t a = s_frame[i], b = s_shown[i];
        if (a == b) continue;
        for (int k = 0; k < 4; k++, a <<= 2, b <<= 2) {
            int cn = a >> 6, cs = b >> 6;
            if (cn == cs) continue;
            int flip = (cn >= 2) != (cs >= 2);
            f += flip;
            int after = flip ? (cn >= 2 ? 3 : 0) : cs;     // what the glass would show after a partial
            d += after != cn;
        }
    }
    *flips = f;
    *debt = d;
}

// the model after a partial: flipped pixels are now plain black or white
static void after_partial(void)
{
    for (int i = 0; i < FRAME_BYTES; i++) {
        uint8_t a = s_frame[i], b = s_shown[i], out = 0;
        for (int k = 0; k < 4; k++, a <<= 2, b <<= 2) {
            int cn = a >> 6, cs = b >> 6;
            int c = (cn >= 2) != (cs >= 2) ? (cn >= 2 ? 3 : 0) : cs;
            out = (uint8_t)(out << 2 | c);
        }
        s_shown[i] = out;
    }
}

/* the grey waveform the panel gets: a copy of the panel's LUT_4GRAY below, made in disp_init, which
 * the console may change a byte at a time (disp_lut_poke) to find greys nearer the middle. how it
 * reads (the 4.2"'s): 5 blocks of 6 groups of 7 bytes, then the frame rate. a group: repeats, four
 * phases, two state repeats. a phase byte: its voltage in the top 2 bits (00 none, 01 VSH1 towards
 * white, 10 VSL towards black), its frames in the low 6. the first block has no voltage at all (the
 * common electrode), then black, dark grey, light grey, white, in code order (RAM 0x26 bit, 0x24 bit) */
static uint8_t s_lut[233];

static void load_lut(const uint8_t *lut)
{
    wr_cmd(0x32);                                 // grey waveform, 227 bytes
    for (int i = 0; i < 227; i++) wr_data(lut[i]);
    wr_cmd(0x3F); wr_data(lut[227]);              // LUT end option
    wr_cmd(0x03); wr_data(lut[228]);              // gate voltage
    wr_cmd(0x04); wr_data(lut[229]); wr_data(lut[230]); wr_data(lut[231]);   // source VSH1/VSH2/VSL
    wr_cmd(0x2C); wr_data(lut[232]);              // VCOM
}

/* ... per panel: LUT_4GRAY, init_4gray(), push(), push_partial() (crowpanel-42.md, crowpanel-579.md) ... */

void disp_init(void)
{
    gpio_config_t out = {
        .pin_bit_mask = (1ULL << EPD_PIN_SCK) | (1ULL << EPD_PIN_MOSI) | (1ULL << EPD_PIN_RES) |
                        (1ULL << EPD_PIN_DC) | (1ULL << EPD_PIN_CS) | (1ULL << EPD_PIN_PWR),
        .mode = GPIO_MODE_OUTPUT,
    };
    ESP_ERROR_CHECK(gpio_config(&out));
    gpio_config_t in = { .pin_bit_mask = 1ULL << EPD_PIN_BUSY, .mode = GPIO_MODE_INPUT };
    ESP_ERROR_CHECK(gpio_config(&in));
    gpio_set_level(EPD_PIN_PWR, 1);               // power the panel
    gpio_set_level(EPD_PIN_CS, 1);
    gpio_set_level(EPD_PIN_RES, 1);
    vTaskDelay(pdMS_TO_TICKS(100));
    int psram = 1;
    s_frame = heap_caps_malloc(FRAME_BYTES, MALLOC_CAP_SPIRAM | MALLOC_CAP_8BIT);
    s_shown = heap_caps_malloc(FRAME_BYTES, MALLOC_CAP_SPIRAM | MALLOC_CAP_8BIT);
    if (!s_frame || !s_shown) {                   // no PSRAM on this board: internal RAM then
        psram = 0;
        if (!s_frame) s_frame = heap_caps_malloc(FRAME_BYTES, MALLOC_CAP_8BIT);
        if (!s_shown) s_shown = heap_caps_malloc(FRAME_BYTES, MALLOC_CAP_8BIT);
    }
    if (!s_frame || !s_shown) { ESP_LOGE(TAG, "no memory for the two frames"); return; }
    memset(s_frame, 0xFF, FRAME_BYTES);
    memset(s_shown, 0xFF, FRAME_BYTES);
    memcpy(s_lut, LUT_4GRAY, sizeof s_lut);
    ESP_LOGI(TAG, "e-paper %dx%d, 4 greys, frames in %s, new picture every %u s", EPD_W, EPD_H,
             psram ? "PSRAM" : "internal RAM", (unsigned)(disp_frame_ms() / 1000));
}

void disp_strip(const canvas_t *cv)
{
    if (s_frame) paper_pack(cv, s_frame);
}

/* --- finding the greys: OWLOS EPDTEST and OWLOS EPDLUT on the console (main.c) --- */

#define TEST_HOLD_US (600LL * 1000000)               // the test stays this long (a photo of it), the radar's pictures wait
static volatile int s_test_req;
static int64_t s_test_until;

void disp_grey_test(void) { s_test_req = 1; }

void disp_lut_poke(int i, int v)
{
    if (v < 0) {
        memcpy(s_lut, LUT_4GRAY, sizeof s_lut);
        ESP_LOGI(TAG, "grey waveform back to the panel's own");
    } else if (i >= 0 && i < (int)sizeof s_lut) {
        ESP_LOGI(TAG, "grey waveform byte %d: %02x -> %02x", i, s_lut[i], v & 255);
        s_lut[i] = (uint8_t)v;
    }
}

/* six bands with paper above and below each to hold them against: the four codes, black to white,
 * then the dot screens the paper screen uses, an eighth (the woods) and a half */
static void grey_test_frame(void)
{
    const int bw = GFX_W / 6, top = GFX_H / 5, bottom = GFX_H - GFX_H / 5;
    for (int y = 0; y < GFX_H; y++) {
        for (int x = 0; x < GFX_W; x++) {
            const int band = x / bw;
            int c = 3;
            if (y >= top && y < bottom && band < 6) {
                if (band < 4) c = band;
                else if (band == 4) c = !(y & 1) && !((x + (y & 2)) & 3) ? 0 : 3;
                else c = (x + y) & 1 ? 3 : 0;
            }
            uint8_t *b = &s_frame[y * PAPER_STRIDE + (x >> 2)];
            const int sh = 6 - 2 * (x & 3);
            *b = (uint8_t)((*b & ~(3 << sh)) | c << sh);
        }
    }
}

/* full grey refresh: new screen, every 10 min, or when too many greys are wrong (but not
 * more than once a minute for that). otherwise the black/white changes go on top. nothing
 * changed: the glass is left alone */
void disp_frame_end(void)
{
    if (!s_frame || !s_shown) return;
    int64_t t0 = esp_timer_get_time();
    if (s_test_req) {                                  // the grey test, printed with the waveform as it is now
        s_test_req = 0;
        grey_test_frame();
        push();
        memcpy(s_shown, s_frame, FRAME_BYTES);
        s_test_until = t0 + TEST_HOLD_US;
        ESP_LOGI(TAG, "grey test: black, dark grey, light grey, white, dots 1/8, dots 1/2; %d ms",
                 (int)((esp_timer_get_time() - t0) / 1000));
        return;
    }
    if (s_test_until) {
        if (t0 < s_test_until) return;                 // it stays on the glass
        s_test_until = 0;
        s_full = 1;                                    // and the radar comes back whole
    }
    int flips, debt;
    count_changes(&flips, &debt);
    int full = s_full || t0 - s_last_full >= FULL_EVERY_US || (debt > GREY_DEBT_MAX && t0 - s_last_full >= FULL_GAP_US);
    if (full) {
        push();
        memcpy(s_shown, s_frame, FRAME_BYTES);
        s_full = 0;
        s_last_full = t0;
        ESP_LOGI(TAG, "4-grey refresh, %d ms (%d px of grey were wrong)", (int)((esp_timer_get_time() - t0) / 1000), debt);
    } else if (flips) {
        push_partial();
        after_partial();
        ESP_LOGI(TAG, "drawn on top, %d px, %d ms, grey debt %d", flips, (int)((esp_timer_get_time() - t0) / 1000), debt);
    }
}

#endif
```

The comment on `disp_frame_end` says "once a minute"; the code's gap is 3 minutes (`FULL_GAP_US`). The code is
right.

## Finding the greys on a new panel

- `OWLOS EPDTEST` on the console prints six bands (the four codes, then a 1/8 and a 1/2 dot screen) with the
  waveform as it is now, and holds them 10 minutes for a photo.
- `OWLOS EPDLUT i v` changes byte i of the grey waveform in RAM until the next start; no value puts it all back.
- A phase byte's top 2 bits are its voltage (00 none, 01 towards white, 10 towards black), its low 6 the frames.
  A grey is frames towards white, then towards black: more white frames, lighter. On the 4.2" one frame either
  way per grey moved both greys to the middle ([crowpanel-42](crowpanel-42.md)).

## Traps

- **`EPD_PIN_PWR` has to be high** or nothing happens.
- **BUSY high means busy.** A refresh takes seconds in `wait_busy`, in a task the watchdog watches: feed it there,
  and stop after 10 s with a log line, so a stuck pin cannot hold the board.
- **The bus is bit-banged**, 1 us half clock, CS up after every byte, as ViewOwl does. A full picture on the wide
  panel is 54,400 bytes, about 0.9 s at that rate [reasoned]. A real SPI would save some of it; nobody needed it.
- **Straight after flashing the S3 prints nothing until a reset**: toggle RTS on an open port to see the boot.
- **Keys read in the screen task miss presses**: the task waits seconds while the glass changes. Read them on a
  task of their own into a queue ([buttons-keys](../buttons-keys.md)).
- **No backlight**: `disp_backlight` does nothing; there is no light to dim.
