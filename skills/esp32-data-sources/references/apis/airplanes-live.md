# airplanes.live: dropped

A community ADS-B network that OWLOS Flight Radar asked once, as a free server beside adsb.lol and adsb.fi.

- It now answers 403 to anyone not let in. It was removed from the firmware's list. [measured]
- A viewer asked for the airline and the flight number, which airplanes.live gives. It stays out: a source that refuses
  strangers cannot be a default. The idea offered instead, not built: the airline from the callsign's ICAO prefix, by a table
  in flash. [reasoned]
- If it is ever asked again, mind that a 403 is an error answer: some networks count those toward an IP block.
