# DS18B20: temperature on one wire

Maxim's 1-Wire thermometer, in a probe. OWLOS Thermo Relay's only sensor: on the 2.8" CYD's CN1 plug, DATA on IO27 with 4.7k from
DATA to 3.3 V (most probe modules have it), VDD on 3.3 V. All three wires: parasite power is not done. From
`code/thermo_ds18b20.c`; the thermostat around it in `../thermo-relay.md`.

How sure: built for the CYD; the notes do not record a long run with a real probe. [built] The timing is Maxim's.

## Bit-banged

Timing from Maxim's application note 126. Open drain, the weak inner pull-up on top of the 4.7k. Each slot runs with interrupts
off (`portENTER_CRITICAL`); the longest is the reset sample at 70 us.

```
reset: low 480 us, let go, sample at 70 us (present = low), 410 us
write: low 6 us for a 1, 60 us for a 0, recovery 64 / 10 us
read:  low 3 us, let go, sample at 10 us, 53 us
SKIP ROM 0xCC, CONVERT T 0x44. a conversion takes 750 ms: start it, read it a second later
READ SCRATCHPAD 0xBE, 9 bytes, CRC8 x^8 + x^5 + x^4 + 1 (0x8C reflected)
raw int16 / 16 = C, kept only between -56 and 126
```

The control task reads what was started a second ago and starts the next, so the 750 ms wait costs nothing:

```c
vTaskDelayUntil(&wake, pdMS_TO_TICKS(1000));
float t = 0;
int ok = started && ds_read(&t);
started = ds_start();
```

## What to know

- All zeros pass the CRC: a line stuck low gives them. So all-zero and all-FF are refused before the CRC is trusted. [built]
- A probe reset by a glitch reads its power-on value, 85.0 C, which this filter lets through. [docs, not seen here] In HEAT that
  trips the limit, the safe side; in COOL it would ask for cooling. Worth a filter in a new design.
- It steps in 1/16 C. The thermostat smooths steps under 2 C (`t += 0.35 (v - t)`) so the last digit does not flicker.
- Three failed reads in a row is a missing probe: relay off at once, `--.-` on the screen.
- The ROM id is shown the way Linux names them: `28-` and twelve hex digits.

## Traps

- A dead line reads as 0 C: all zeros pass the CRC. Refuse all-zero and all-FF. [built]
