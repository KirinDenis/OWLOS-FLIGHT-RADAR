# ILI9341 (and ILI9341V)

240x320 SPI panel, run in landscape 320x240 through `lcd_spi.c` ([bus-spi-strips](../bus-spi-strips.md)).
Sureness words as in [SKILL.md](../../SKILL.md).

## Where it is

- 2.8" CYD ESP32-2432S028R, v1 (micro USB) [measured: the board the firmware was written on, 15 to 19 fps,
  a 2 h log clean, no reboot, 0 lost strips; 49 KB heap left in WiFi Radar; with the second core's halves
  RADAR 12, MAP 19, CLASSIC 15 fps in Flight Radar] and v2 (USB-C) [built: no v2 on the desk]. Board file:
  [ili9341](../../../esp32-boards/references/boards/ili9341.md).
- LCDWIKI E32R28T (2.8" ESP32-32E, also sold by Elegoo): ILI9341V on exactly the CYD's pins, reset on EN.
  Takes the CYD build. FusionEdge's CYD build runs on two of them here [measured with FusionEdge]; the radar's
  build not run on one. Board file: [e32r28t](../../../esp32-boards/references/boards/e32r28t.md).
- LCDWIKI ES3C28P (ESP32-S3, ILI9341V IPS): BGR with inversion on, the v2 start-up, MADCTL 0x28 [built]. Board
  file: [es3c28p](../../../esp32-boards/references/boards/es3c28p.md).
- Not ported, the same chip: ESP32-2432S024 C/R/N (2.4"), the plain Elecrow CrowPanel 2.8 and 2.4 (ILI9341V,
  XPT2046 on the LCD bus), some batches of the Guition JC2432W328C (ST7789 in others).

## MADCTL and inversion

- CYD v1: 0xE8 (MY|MX|MV|BGR), inversion off [measured]. v2 the same way round, inversion on [built].
- ES3C28P: 0x28 (MV|BGR), Bruce's landscape; the other one is the screen turned over. Inversion on [built].
- These are the "MX equal to MY" family: landscapes 0x20 and 0xE0, with BGR 0x28 and 0xE8.
- A v3 CYD is an ST7789: [st7789](st7789.md).

## The tables

Where the values came from: v1 from Espressif's esp_lcd_ili9341 1.2.0 (Apache 2.0), the same as ViewOwl
(an earlier firmware of ours) uses on this panel; v2 from rzeldent/platformio-espressif32-sunton's board
files, turned into our landscape. `LCD_MADCTL` is the board's value. Every table that can follow another
begins with software reset 0x01: the CYD has its LCD reset tied high, so software reset is the only reset.
The format (`init_cmd_t` in [bus-spi-strips](../bus-spi-strips.md)): command, parameter count, up to 15
parameters, and `wait_ms`, the wait after the command.

```c
    { 0xED, 4, { 0x67, 0x03, 0x12, 0x81 }, 0 },              /* power on sequence */
    { 0xE8, 3, { 0x8A, 0x01, 0x78 }, 0 },                    /* driver timing A */
    { 0xCB, 5, { 0x39, 0x2C, 0x00, 0x34, 0x02 }, 0 },        /* power control A */
    { 0xF7, 1, { 0x20 }, 0 },                                /* pump ratio */
    { 0xEA, 2, { 0x00, 0x00 }, 0 },                          /* driver timing B */
    { 0xC0, 1, { 0x23 }, 0 },                                /* power control 1 */
    { 0xC1, 1, { 0x11 }, 0 },                                /* power control 2 */
    { 0xC5, 2, { 0x43, 0x4C }, 0 },                          /* VCOM 1 */
    { 0xC7, 1, { 0xA0 }, 0 },                                /* VCOM 2 */
    { 0xB1, 2, { 0x00, 0x1B }, 0 },                          /* frame rate 70 Hz */
    { 0xF2, 1, { 0x00 }, 0 },                                /* 3-gamma off */
    { 0x26, 1, { 0x01 }, 0 },                                /* gamma curve 1 */
    { 0xE0, 15, { 0x1F, 0x36, 0x36, 0x3A, 0x0C, 0x05, 0x4F, 0x87, 0x3C, 0x08, 0x11, 0x35, 0x19, 0x13, 0x00 }, 0 },
    { 0xE1, 15, { 0x00, 0x09, 0x09, 0x05, 0x13, 0x0A, 0x30, 0x78, 0x43, 0x07, 0x0E, 0x0A, 0x26, 0x2C, 0x1F }, 0 },
    { 0xB7, 1, { 0x07 }, 0 },                                /* entry mode */
    { 0xB6, 3, { 0x08, 0x82, 0x27 }, 0 },                    /* display function */
    { 0x36, 1, { LCD_MADCTL }, 0 },                          /* landscape, BGR */
    { 0x3A, 1, { 0x55 }, 0 },                                /* 16 bits a pixel */
    { 0x20, 0, { 0 }, 0 },                                   /* no inversion */

/* the other two CYD revisions (board.h). values from rzeldent/platformio-espressif32-sunton,

static const init_cmd_t INIT_V2[] = {                         /* USB-C: ILI9341, its own power and gamma */
    { 0x01, 0, { 0 }, 120 },
    { 0xCF, 3, { 0x00, 0xC1, 0x30 }, 0 },
    { 0xED, 4, { 0x64, 0x03, 0x12, 0x81 }, 0 },
    { 0xE8, 3, { 0x85, 0x00, 0x78 }, 0 },
    { 0xCB, 5, { 0x39, 0x2C, 0x00, 0x34, 0x02 }, 0 },
    { 0xF7, 1, { 0x20 }, 0 },
    { 0xEA, 2, { 0x00, 0x00 }, 0 },
    { 0xC0, 1, { 0x10 }, 0 },
    { 0xC1, 1, { 0x00 }, 0 },
    { 0xC5, 2, { 0x30, 0x30 }, 0 },
    { 0xC7, 1, { 0xB7 }, 0 },
    { 0x3A, 1, { 0x55 }, 0 },
    { 0x36, 1, { LCD_MADCTL }, 0 },                          /* same way round as v1 */
    { 0xB1, 2, { 0x00, 0x1A }, 0 },
    { 0xB6, 3, { 0x08, 0x82, 0x27 }, 0 },
    { 0xF2, 1, { 0x00 }, 0 },
    { 0x26, 1, { 0x01 }, 0 },
    { 0xE0, 15, { 0x0F, 0x2A, 0x28, 0x08, 0x0E, 0x08, 0x54, 0xA9, 0x43, 0x0A, 0x0F, 0x00, 0x00, 0x00, 0x00 }, 0 },
    { 0xE1, 15, { 0x00, 0x15, 0x17, 0x07, 0x11, 0x06, 0x2B, 0x56, 0x3C, 0x05, 0x10, 0x0F, 0x3F, 0x3F, 0x0F }, 0 },
    { 0x21, 0, { 0 }, 0 },                                   /* inversion on: this panel needs it */
    { 0x11, 0, { 0 }, 120 },

/* INIT_V3, the ST7789 start-up of a v3 CYD, is in st7789.md */

```

- v1: sleep out comes second; v2: sleep out comes last. `data[15]` in `init_cmd_t` is the longest parameter
  list there is, these gammas.
- The CYD build carries all three start-ups as screen profiles, list order v1, v2, v3 (frozen: boards save
  the index), BOOT order { 1, 0, 2 }: a board that never picked one starts as v2, because most sold are v2.
  The ES3C28P carries the same three, v2 first. Profiles: [SKILL.md](../../SKILL.md), section 6.

## What goes wrong

- **v1 table on a v2 panel**: noise, negative colours, or upside down: the power and gamma values of the
  other revision (WiFi Radar's README). Fix: profiles, v2 first.
- **v1 table on a v3 (ST7789) panel**: light blue on white and upside down (a viewer's report, the reason v3
  is in the build).
- **No MISO on the 2.8" CYD**: GPIO 12 is a strapping pin. The panel is never read, so no ID read could tell
  v1 from v2 anyway: they are the same chip.

## FusionEdge on the same panel

FusionEdge drives the CYD's ILI9341 through LovyanGFX's `Panel_ILI9341`, rotation from its options, SPI at
27 MHz write, 12 MHz read; inversion is a stored user setting (`invertdisplay`) and a flip is rotation + 2
[docs, its source; measured on the E32R28T here with its lite screen].
