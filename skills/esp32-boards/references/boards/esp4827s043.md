# ESP32-4827S043C, 4.3" 480x272 (build `esp4827s043`)

Sunton's 4.3" 480x272 on the S3's RGB bus, sold as C (capacitive GT911), R (resistive XPT2046) and N (no touch). This
build is for the C.

- Build: `esp4827s043`, `RADAR_DISPLAY` 13 (`DISPLAY_4827S043_480x272`), target esp32s3.
- How sure: built 2026-11-09, experimental, not run on one. Its owner tests it.
- How it was asked: first "will one of the binaries work with the older Guition 4.3" ESP32 modules?" (2026-11-07), then
  "my display is not one you have firmware for... The display is an ESP32-4827S043". They tried a couple of builds: no
  picture on most; the 5" one showed a picture that "spills over", as an 800x480 frame on a 480x272 glass would. That
  told the data, sync and touch pins are the JC8048W550's. No letter printed on the board; it is a touch screen, so C
  or R; "I believe the version I have is a capacitive type". They have two, one ran openHASP before.

## Chip, flash, PSRAM, USB

ESP32-S3 N16R8 by the JSON ([esp32-s3](../chips/esp32-s3.md)); the 5" build (octal PSRAM, frame in it) showed its
picture here, so the S3 RGB settings stay as they are. A CH340; SDA and SCL on the S3's USB pins (`NO_CHIP_USB`).

## Screen

480x272 on the RGB bus, the JC8048W550's pins, its own timing: 8 MHz, HSYNC pulse 4, back 43, front 8; VSYNC pulse 4,
back 12, front 8. Bounce buffers of 8 rows: 272 does not divide by the 5"'s 10, and esp_lcd refuses a frame that does
not. Backlight 2, high = lit. Bus: ../../../esp32-lcd-touch/references/bus-rgb.md.

A layout of its own at 480x272, one pixel one pixel: every size switch in core/ asks `GFX_H >= 320`, so it takes the
2.8"'s letters and rows with a wider panel (PC preview shots/esp4827s043, all pages fit). Strips of 16 rows, 17 strips.

## Touch

GT911 on I2C SDA 19, SCL 20, RST 38, INT 18. ../../../esp32-lcd-touch/references/touch/gt911.md. The R version's
XPT2046 on its own SPI would be the next build if the touch is dead.

## board.h

```c
#elif RADAR_DISPLAY == DISPLAY_4827S043_480x272
/* ESP32-4827S043C, 4.3": ESP32-S3 N16R8, 480x272 on the RGB bus, GT911, a CH340. pins and timing from
 * rzeldent/platformio-espressif32-sunton, esp32-4827S043C.json: the pins are the JC8048W550's, and an
 * owner's 4827S043 showed that build's picture, too big for its glass. the panel's timing is its
 * own: 8 MHz, 43 clocks before a row and 12 rows before a frame. NOT run on one: experimental, its
 * owner tests it. the R version has a resistive XPT2046 instead, not in this build */
#define DISP_LCD_RGB   1
#define LCD_RGB_DATA   8, 3, 46, 9, 1,  5, 6, 7, 15, 16, 4,  45, 48, 47, 21, 14   // blue, green, red, lowest bit first
#define PIN_LCD_HSYNC 39
#define PIN_LCD_VSYNC 41
#define PIN_LCD_DE    40
#define PIN_LCD_PCLK  42
#define LCD_RGB_HZ    (8 * 1000 * 1000)
#define LCD_RGB_H_BACK 43
#define LCD_RGB_V_BACK 12
#define LCD_RGB_BOUNCE 8        // rows a bounce buffer: 272 divides by it, not by the 5"'s 10
#define PIN_LCD_BL     2        // high = lit
#define DISP_STRIP    16        // 17 strips
#define DISP_HELPER   1
#define LCD_PROFILES   2
#define LCD_ORDER      { 0, 1 }
#define TOUCH_GT911    1
#define PIN_I2C_SDA   19        // the S3's own USB pins: this board has a CH340, they are free
#define PIN_I2C_SCL   20
#define PIN_T_RST     38
#define PIN_T_INT     18
#define NO_CHIP_USB    1
#define PIN_BUTTON     0        // BOOT
```

## sdkconfig and partitions

`sdkconfig.defaults` + `.esp32s3` + `.s3lcd` + `.s3rgb`: 4 MB, `partitions.csv`. App 1,225,088 bytes (built). The web
twin builds a size for it (Twin5).
