# FT6336 (capacitive, FT5x06 family)

Capacitive touch on I2C at 0x38. Source: OWLOS Flight Radar `firmware/main/touch.c`, which reads it with the same
code as the CST816 ([cst816](cst816.md)). Sureness words as in [SKILL.md](../../SKILL.md).

## Where it is

- LCDWIKI ES3C28P (FT6336G) [built]. Board file: [es3c28p](../../../esp32-boards/references/boards/es3c28p.md).
- Elecrow CrowPanel Advance 2.8" (FT6336U) [built]. Board file:
  [crowadv28](../../../esp32-boards/references/boards/crowadv28.md).
- FusionEdge reads the same chip through LovyanGFX's `Touch_FT5x06` at 0x38 (its `TS_MODEL_FT6X36`) on the
  CrowPanel Advance 2.8" and the gen4-ESP32 3.5" CT, with the reset and INT pins given [docs].
- Not ported: WT32-SC01 (3.5" ST7796 with an FT6336).

## The facts

- Own reset GPIO: low 10 ms, high, then 300 ms before it answers. Probed at 0x38; nothing there: on without
  touch, BOOT still works.
- It knows two fingers at most: a count above 2 is a register not ready yet: ignore it.
- The first finger, as the CST816 gives it: read 5 bytes from register 0x02: the count of fingers (`& 0x0F`), X
  high and low, Y high and low (`& 0x0F` on the high bytes).
- It counts the pixels of the portrait glass, 240x320 standing, so in landscape expect a swap. The alignment
  sorts it out. `TOUCH_RAW_SPAN` 320.
- INT is wired on both boards and not used: the chip is asked every sample.
- Elecrow's trap: one of its sketches starts a GT911 at 0x5D left over from another board. The CrowPanel Advance
  2.8"'s touch is read through LovyanGFX's FT5x06 at 0x38, and Elecrow's wiki says 0x38. If a board shows no
  touch at all, look there first. A maker's sketch may start chips left over from another board.

## The code

```c
#elif TOUCH_CST816 || TOUCH_FT6336
/* the CST816 (round board) and the FT6336 (ES3C28P, CrowPanel Advance) give the first finger
 * the same way: from register 0x02 on, the count of fingers, X high and low, Y high and low */
#include "i2c_bus.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#if TOUCH_FT6336
#include "driver/gpio.h"
#define TOUCH_ADDR FT6336_ADDR
#define TOUCH_CHIP "FT6336"
#else
#define TOUCH_ADDR CST816_ADDR
#define TOUCH_CHIP "CST816"
#endif

static i2c_master_dev_handle_t s_dev;

void tp_init(void)
{
#if TOUCH_FT6336
    // its reset is a GPIO of its own: held low a moment, then up, and the chip wants a while
    // after that before it answers
    gpio_config_t rst = { .pin_bit_mask = 1ULL << PIN_T_RST, .mode = GPIO_MODE_OUTPUT };
    gpio_config(&rst);
    gpio_set_level(PIN_T_RST, 0);
    vTaskDelay(pdMS_TO_TICKS(10));
    gpio_set_level(PIN_T_RST, 1);
    vTaskDelay(pdMS_TO_TICKS(300));
#else
    // the expander let the touch out of reset in disp_init, give it a moment to wake
    vTaskDelay(pdMS_TO_TICKS(50));
#endif
    if (!i2c_probe(TOUCH_ADDR)) {
        ESP_LOGW(TAG, "nothing at 0x%02x, going on without touch (BOOT button still works)", TOUCH_ADDR);
        return;
    }
    s_dev = i2c_dev(TOUCH_ADDR);
#if TOUCH_CST816
    // the CST816 dozes off after a few idle seconds and then ignores I2C untill touched. 0xFE = 1 keeps it awake
    i2c_master_transmit(s_dev, (const uint8_t[]){ 0xFE, 0x01 }, 2, 50);
#endif
    ESP_LOGI(TAG, TOUCH_CHIP " at 0x%02x", TOUCH_ADDR);
}

int tp_read(int *rx, int *ry)
{
    if (!s_dev) return 0;
    uint8_t reg = 0x02, b[5];                     // finger count, X high, X low, Y high, Y low
    if (i2c_master_transmit_receive(s_dev, &reg, 1, b, sizeof b, 20) != ESP_OK) return 0;
    const int fingers = b[0] & 0x0F;
    if (!fingers) return 0;
#if TOUCH_FT6336
    if (fingers > 2) return 0;                    // it knows two at most: more is a register not ready yet
#endif
    *rx = ((b[1] & 0x0F) << 8) | b[2];
    *ry = ((b[3] & 0x0F) << 8) | b[4];
    return 1;
}
```

The I2C bus under it: [i2c](../i2c.md). A touch read has a 20 ms timeout, a probe 50 ms.
