# Guition JC8048W550, 5" (build `jc8048w550`)

Guition's 5" 800x480 on the S3's RGB bus, GT911 touch, a CH340. The same pins as Sunton's ESP32-8048S050C.

- Build: `jc8048w550`, `RADAR_DISPLAY` 11 (`DISPLAY_JC8048W550_800x480`), target esp32s3.
- How sure: built 2026-11-05, experimental, not run on one. Pins from one source so far (rzeldent's JSON). Named in a
  group ask of 2026-11-04 ("ILI9488 TFT's or a Guition ESP32-S3 JC8048W550 ... just needs a bigger display size
  option"); which board the asker owns, and whether they would test, is not known.
- Its pins are confirmed in part by another board: an ESP32-4827S043 owner flashed this build and got a picture that
  spilled over its smaller glass ([esp4827s043](esp4827s043.md)).

## Chip, flash, PSRAM, USB

ESP32-S3 N16R8 ([esp32-s3](../chips/esp32-s3.md)), PSRAM `qio_opi` in the JSON (octal), 16 MB. A CH340; SDA and SCL are
the S3's own USB pins, so the console stays off that USB (`NO_CHIP_USB`). A version without touch exists by one
manual.

## Screen

800x480, ST7262 by a shop's listing, 16 MHz pixel clock, PCLK active negative, frame in PSRAM. HSYNC 39, VSYNC 41,
DE 40, PCLK 42. Porches: pulse 4, back 8, front 8 both ways. Backlight 2, high = lit (PWM). Bus:
../../../esp32-lcd-touch/references/bus-rgb.md, panel ../../../esp32-lcd-touch/references/panels/st7262.md.

Data lines, lowest bit first: 8 3 46 9 1, 5 6 7 15 16 4, 45 48 47 21 14. The JSON names the low five red; every other
setup for those pins has them blue, and the bus's low five are blue, so they go in as listed with BGR behind BOOT in
case (`LCD_ORDER { 0, 1 }`). The same code and layout as [crowadv50](crowadv50.md).

## Touch

GT911 at 0x5D on I2C SDA 19, SCL 20, RST 38, INT 18. ../../../esp32-lcd-touch/references/touch/gt911.md.

## Other parts

SD CS 10, MOSI 11, SCLK 12, MISO 13 (JSON, not driven). BOOT 0.

## board.h

```c
#elif RADAR_DISPLAY == DISPLAY_JC8048W550_800x480
/* Guition JC8048W550C, 5": ESP32-S3 N16R8, 800x480 on the RGB bus (ST7262), GT911, a CH340. pins from
 * one source so far, rzeldent/platformio-espressif32-sunton, JC8048W550C.json: the same as its
 * ESP32-8048S050C. that file calls the low five data lines red, and every other setup for those
 * pins has them blue: the bus's low five are blue, so these go in as listed. NOT run on one:
 * experimental, a viewer asked for it. a version without touch is sold too */
#define DISP_LCD_RGB   1
#define LCD_RGB_DATA   8, 3, 46, 9, 1,  5, 6, 7, 15, 16, 4,  45, 48, 47, 21, 14   // blue, green, red, lowest bit first
#define PIN_LCD_HSYNC 39
#define PIN_LCD_VSYNC 41
#define PIN_LCD_DE    40
#define PIN_LCD_PCLK  42
#define LCD_RGB_HZ    (16 * 1000 * 1000)
#define PIN_LCD_BL     2        // high = lit
#define DISP_STRIP    12        // as the CrowPanel's
#define DISP_HELPER   1
#define LCD_PROFILES   2
#define LCD_ORDER      { 0, 1 }
#define TOUCH_GT911    1
#define PIN_I2C_SDA   19        // the S3's own USB pins: this board has a CH340, they are free
#define PIN_I2C_SCL   20
#define PIN_T_RST     38
#define PIN_T_INT     18
#define NO_CHIP_USB    1
#define PIN_BUTTON     0        // BOOT
```
