# GT911 (capacitive)

Capacitive touch on I2C, 16-bit register addresses, MSB first. Source: OWLOS Flight Radar `firmware/main/touch.c`,
`lcd_rgb.c`, chipguyhere's Waveshare 7/7B library. Sureness words as in [SKILL.md](../../SKILL.md).

## Where it is

- 3.5" CYD, C version (ESP32-3248S035C): asked for before the R version's XPT2046 (`TOUCH_GT911_TOO`) [built: not
  run on a C version; the probing runs every boot on the R version here, measured].
- The S3 RGB boards (`TOUCH_GT911`): CrowPanel Advance 5.0 [measured on a tester's V1.3], JC8048W550,
  ESP32-4827S043C, CrowPanel 7.0, CrowPanel 5.0 plain [built], Waveshare 7 and 7B [measured by its
  contributor].
- The Tab5 with the ILI9881C panel, through the board package (not seen).
- FusionEdge has LovyanGFX's `Touch_GT911` in its options [docs].
- Not ported: ESP32-2432S032C (GT911 at 0x5D), JC4827W543C.

## Addresses and reset

- 0x5D or 0x14, picked by the INT line's level while the chip comes out of reset. Ask both; "911" at register
  0x8140 proves it is one (something else may answer at those addresses).
- INT held low through the reset gives 0x5D. INT may not be driven high afterwards: the chip drives it too. Let
  it go to input.
- Where the reset is, by board:
  - its own GPIO (JC8048W550, ESP32-4827S043C): INT low, RST low 10 ms, RST high, 10 ms, INT to input, 60 ms;
  - the CrowPanel Advance 5.0's board chip (PCA9557 on V1.0, an STC8H1K28 later): done in lcd_rgb.c
    ([bus-rgb](../bus-rgb.md));
  - a PCA9557 at 0x18 on the plain CrowPanel 5.0 and 7.0 (P0 the reset, P1 the INT), below;
  - the Waveshare 7/7B's expander, through chipguyhere's library (`touchReset()`: INT low through a reset
    pulse, 0x5D), before `tp_init`;
  - nowhere on the 3.5" CYD C: just probe.

## Reading it

- Status 0x814E: bit 7 fresh data, low bits the number of fingers. Then 0x8150: X low, X high, Y low, Y high.
  Write 0 back to 0x814E after reading.
- It reports about every 10 ms while a finger is on, so 300 ms of silence counts as lifted.
- It counts the glass's own pixels: portrait 320x480 on the 3.5", 800x480 lying on the 5". `TOUCH_RAW_SPAN` is
  `GFX_PW` (480 on the 3.5" C, found at run time because that board learns its touch in `tp_init`).
- The plain CrowPanel 5.0's GT911 wants a stop between the register address and the read: a repeated start comes
  back empty (`GT911_STOP`), and its bus runs at 100 kHz (`I2C_BUS_HZ`) [built, from the P2000 firmware that runs
  on that board].

```c
#if TOUCH_GT911_TOO || TOUCH_GT911
/* GT911, capacitive (board.h). 16-bit register addresses, MSB first. its address is 0x5D or 0x14,
 * picked by the INT level at power on: both are asked, and "911" at 0x8140 tells it is really one.
 * it counts in screen pixels: portrait 320x480 on the 3.5", 800x480 lying down on the 5" */
#include "i2c_bus.h"
#include "esp_timer.h"

static i2c_master_dev_handle_t s_gt;
static int      s_gt_down, s_gt_x, s_gt_y;
static int64_t  s_gt_seen;

static int gt_reg(uint16_t reg, uint8_t *buf, int n)
{
    uint8_t r[2] = { (uint8_t)(reg >> 8), (uint8_t)reg };
#ifdef GT911_STOP
    /* this panel's GT911 wants a stop after the register, then the read. a repeated start comes back empty */
    if (i2c_master_transmit(s_gt, r, 2, 20) != ESP_OK) return 0;
    return i2c_master_receive(s_gt, buf, (size_t)n, 20) == ESP_OK;
#else
    return i2c_master_transmit_receive(s_gt, r, 2, buf, (size_t)n, 20) == ESP_OK;
#endif
}

static int gt_find(void)
{
    const uint8_t addr[2] = { 0x5D, 0x14 };
    for (int i = 0; i < 2; i++) {
        if (!i2c_probe(addr[i])) continue;
        s_gt = i2c_dev(addr[i]);
        uint8_t id[4] = { 0 };
        if (gt_reg(0x8140, id, 4) && id[0] == '9' && id[1] == '1' && id[2] == '1') {
            ESP_LOGI(TAG, "GT911 at 0x%02x", addr[i]);
            return 1;
        }
        i2c_master_bus_rm_device(s_gt);              // something else answered, not ours
        s_gt = NULL;
    }
    return 0;
}

/* status 0x814E: bit 7 = fresh data, low bits = how many fingers. after reading it wants a 0 back.
 * while a finger is on it reports about every 10 ms, so a silence of 300 ms counts as lifted */
static int gt_read(int *rx, int *ry)
{
    uint8_t st = 0;
    int64_t now = esp_timer_get_time();
    if (gt_reg(0x814E, &st, 1) && (st & 0x80)) {
        uint8_t p[4];
        if ((st & 0x0F) && gt_reg(0x8150, p, 4)) {
            s_gt_x = p[0] | p[1] << 8;
            s_gt_y = p[2] | p[3] << 8;
            s_gt_down = 1;
        } else {
            s_gt_down = 0;
        }
        const uint8_t clr[3] = { 0x81, 0x4E, 0 };
        i2c_master_transmit(s_gt, clr, 3, 20);
        s_gt_seen = now;
    } else if (s_gt_down && now - s_gt_seen > 300000) {
        s_gt_down = 0;
    }
    if (s_gt_down) { *rx = s_gt_x; *ry = s_gt_y; }
    return s_gt_down;
}
#endif
```

`tp_init` where the GT911 is the only touch (`TOUCH_GT911`):

```c
void tp_init(void)
{
#ifdef PIN_T_RST
    /* its reset is a GPIO of its own: INT low through it picks 0x5D. on the CrowPanel the board's
     * own chip has done this by now (lcd_rgb.c) */
    gpio_config_t out = { .pin_bit_mask = 1ULL << PIN_T_RST | 1ULL << PIN_T_INT, .mode = GPIO_MODE_OUTPUT };
    gpio_config(&out);
    gpio_set_level(PIN_T_INT, 0);
    gpio_set_level(PIN_T_RST, 0);
    vTaskDelay(pdMS_TO_TICKS(10));
    gpio_set_level(PIN_T_RST, 1);
    vTaskDelay(pdMS_TO_TICKS(10));
    gpio_config_t in = { .pin_bit_mask = 1ULL << PIN_T_INT, .mode = GPIO_MODE_INPUT };
    gpio_config(&in);
    vTaskDelay(pdMS_TO_TICKS(60));
#endif
#ifdef TOUCH_PCA9557_BOOT
    /* DIS07050H, the sequence the P2000 firmware runs before it looks for the GT911.
     * P0 is the touch's reset, P1 its interrupt */
    {
        i2c_master_dev_handle_t x = i2c_dev(TOUCH_PCA9557_BOOT);
        const uint8_t prep[][2] = { { 3, 0xFF }, { 1, 0xFF }, { 2, 0x00 }, { 3, 0x00 }, { 1, 0xFE }, { 1, 0xFC } };
        int ok = 1;
        for (int i = 0; i < 6; i++) ok = ok && i2c_master_transmit(x, prep[i], 2, 50) == ESP_OK;
        vTaskDelay(pdMS_TO_TICKS(20));
        const uint8_t rel[2] = { 1, 0xFD };
        ok = ok && i2c_master_transmit(x, rel, 2, 50) == ESP_OK;
        vTaskDelay(pdMS_TO_TICKS(100));
        const uint8_t let_go[2] = { 3, 0xFE };
        ok = ok && i2c_master_transmit(x, let_go, 2, 50) == ESP_OK;
        vTaskDelay(pdMS_TO_TICKS(60));
        ESP_LOGI(TAG, "PCA9557 touch reset %s", ok ? "taken" : "not taken");
    }
#endif
#ifdef TOUCH_RESET_PCA9557
    /* the CrowPanel 7.0: its reset is IO0 of a PCA9557, its INT IO1. ESPHome's people found that a
     * reset at every start broke the touch, and an older V3.0 example of Elecrow's leaves the chip
     * alone: so only when the touch is silent, Elecrow's own order then, INT low through the reset
     * for 0x5D. IO2 and up, the panel's reset and power among them, stay as they are */
    if (!gt_find() && i2c_probe(TOUCH_RESET_PCA9557)) {
        i2c_master_dev_handle_t x = i2c_dev(TOUCH_RESET_PCA9557);
        const uint8_t low[2] = { 1, 0xFC }, out[2] = { 3, 0xFC }, up[2] = { 1, 0xFD }, let_go[2] = { 3, 0xFE };
        int ok = i2c_master_transmit(x, low, 2, 50) == ESP_OK;  // the levels first: IO0 and IO1 low
        ok = ok && i2c_master_transmit(x, out, 2, 50) == ESP_OK; // then those two driven
        vTaskDelay(pdMS_TO_TICKS(20));
        ok = ok && i2c_master_transmit(x, up, 2, 50) == ESP_OK;  // out of reset, INT still low
        vTaskDelay(pdMS_TO_TICKS(100));
        ok = ok && i2c_master_transmit(x, let_go, 2, 50) == ESP_OK;   // INT is the touch's again
        vTaskDelay(pdMS_TO_TICKS(60));
        ESP_LOGW(TAG, "the touch was silent: reset through the PCA9557%s", ok ? "" : ", which did not take it all");
    }
#endif
    if (!s_gt && !gt_find()) ESP_LOGW(TAG, "no GT911, going on without touch%s", RADAR_HAS_BUTTON ? " (BOOT button still works)" : "");
}

int tp_read(int *rx, int *ry) { return s_gt ? gt_read(rx, ry) : 0; }
```

PCA9557 registers as used above: 1 output levels, 2 polarity, 3 direction (1 = input). Set the levels before
making the pins outputs, so nothing glitches.

## The 3.5" CYD: GT911 first, then the XPT2046

The C version has the GT911 on SDA 33, SCL 32; the R version's XPT2046 chip select is 33. So `tp_init` brings up
I2C, asks both addresses, and when nobody answers takes the bus down and gives the pin back (`i2c_bus_free`), then
adds the XPT2046 ([xpt2046](xpt2046.md)). Without that, GPIO 33 stays dead for the XPT2046: I2C still owns it.

Probing an empty address on the classic ESP32 is fine: the NACK, the stop, the bus is free [measured: the 3.5" R
version probes 0x5D and 0x14 every boot]. What can spin for ever on the classic ESP32 is a NACK with something
still holding the bus ([i2c](../i2c.md)). The GT911 path on the classic ESP32 uses the IDF driver and has not run
on a C version: keep that in mind if one locks up [reasoned].

## Alignment on the big boards

- The 5", 7" and 4.3" boards run the 5 cross alignment like every touch board.
- The Waveshare 7/7B builds skip it: their GT911 counts the glass's own pixels, so the map is the glass scaled to
  the layout (`a = GFX_W / GFX_PW`, `e = GFX_H / GFX_PH`), turned with the picture when it is turned. A port of
  that build to a resistive panel wants the alignment back ([touch-alignment](../touch-alignment.md)).
