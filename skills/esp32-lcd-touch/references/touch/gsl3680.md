# GSL3680 (capacitive, Silead)

The touch of the Guition JC8012P4A1C (10.1", ESP32-P4), read through chipguyhere's vendored library
(`firmware/components/chipguy_jc8012/gsl3680_touch.cpp`, MIT). Sources: OWLOS Flight Radar `FORK-NOTES.md`,
`README.md`, `lcd_jc8012_panel.cpp`, `touch.c`. Runs on its contributor's board [measured, a contributor's
board]; not run here. Sureness words as in [SKILL.md](../../SKILL.md). Board file:
[jc8012](../../../esp32-boards/references/boards/jc8012.md).

## It runs from RAM: its firmware is uploaded at every power-up

- About 18 KB of Silead's controller firmware goes into the chip at every power-up. That firmware is GPL-2.0, so
  it is not in the MIT tree.
- The driver reads it from NVS (namespace `jc8012`, key `gsl3680fw`), checks its SHA-256 and uploads it.
- It is put into NVS once per board by the `InstallFirmware` example of chipguyhere's
  `chipguy_ESP32-P4-C6-firmware-installer` Arduino library (github.com/chipguyhere/ESP32-P4-C6-firmware-installer).
- The order: the installer first, then the radar. The installer's partition table puts NVS at 0x9000 to 0xDFFF
  (20 KB) and otadata at 0xE000; the radar's `partitions_jc8012.csv` has NVS at 0x9000 to 0xEFFF (24 KB). After
  the installer, flashing the radar kept the blob: NVS accepted the Arduino otadata in its sixth page without the
  "no free pages" error that would make `app_main` erase it, and the touch came up [measured by its contributor].
- Without the firmware the radar runs with the touch off and the log says `no touch: touch firmware not
  installed in NVS`.

## Bring-up and failure

- The touch is started with the panel by the library, on the board's shared I2C bus; starting it twice is
  harmless.
- A watchdog reboot can catch the GSL3680's I2C mid-transaction and leave it wedged. So a controller that does not
  answer is worth a reset and a reboot, while the panel's bring-up budget lasts (3 in a row, [jd9365](../panels/jd9365.md)).
  Firmware missing from NVS will not appear on its own: then the board comes up with the touch off, never dark.
- The library filters the reports; the firmware keeps the touch driver's bring-up INFO lines out of the log
  (`esp_log_level_set("gsl3680", ESP_LOG_WARN)`).

## Coordinates

It counts the standing glass's pixels, 800 x 1280. `jc_touch` hands them over turned to the lying picture's
1280 x 800, the way lcd_jc8012.c turns the picture in its normal orientation:

```c
extern "C" int jc_touch(int *x, int *y)
{
    if (!s_disp.touchAvailable()) return 0;
    uint16_t px, py;
    if (!s_disp.getTouchDriver().getTouch(&px, &py)) return 0;
    *x = JC8012_NATIVE_HEIGHT - 1 - py;
    *y = px;
    return 1;
}
```

`touch.c` then only forwards it (`TOUCH_JC8012`). A flip turns the touch map with the picture (main.c). Like the
Waveshare 7/7B builds, this build skips the 5 cross alignment: the map is the glass scaled down to the layout
([touch-alignment](../touch-alignment.md)). `TOUCH_RAW_SPAN` is `GFX_PW`.
