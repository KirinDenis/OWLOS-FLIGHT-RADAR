# CCS811: eCO2 and TVOC

ams' metal-oxide gas sensor on I2C. On the OWLOS Air Quality board at 0x5A, HW version 0x12, APP 1.1.0. It gives eCO2 in ppm
and TVOC in ppb. From `code/aq_sensor_hw.c`; the board in `../air-quality.md`.

How sure: started and read on the board. [measured] The waits are Adafruit's library's, which the old firmware ran on.

## Start, in this order

- Software reset: write 0xFF the bytes 11 E5 72 8A, wait 100 ms.
- HW_ID: read 0x20, must be 0x81.
- HW version 0x21 and FW version 0x24 (2 bytes): for the info line.
- STATUS: read 0x00, bit 0x10 APP_VALID.
- APP_START: write the address 0xF4 alone, wait 100 ms.
- STATUS: read 0x00, bit 0x80 FW_MODE.
- MEAS_MODE: write 0x01 the byte 0x10: a result every second.

## Reading: STATUS on its own FIRST, then the result

```c
/* STATUS on its own first, then the result: the status byte inside ALG_RESULT_DATA never
 * showed DATA_READY on this board (seen in the log: STATUS 90 every time), the STATUS
 * register is what Adafruit's library asks, and the old firmware ran on that */
if (!i2c_rd(s_ccs, 0x00, &st, 1)) return -1;
if (st & 0x01) { i2c_rd(s_ccs, 0xE0, &e, 1); s->ccs_error = e; return -2; }   // reading ERROR_ID clears it
if (!(st & 0x08)) return 0;                                                   // DATA_READY
if (!i2c_rd(s_ccs, 0x02, b, 8)) return -1;                                    // ALG_RESULT_DATA
s->eco2 = (float)((b[0] << 8) | b[1]);
s->tvoc = (float)((b[2] << 8) | b[3]);
// RAW_DATA: 6 bits of current (uA), 10 bits of voltage over its sensing layer (1.65 V full)
s->ccs_ua = (float)(b[6] >> 2);
s->ccs_v = (float)(((b[6] & 3) << 8) | b[7]) * (1.65f / 1023.0f);
```

## What to know

- It is told the temperature and humidity once a minute, ENV_DATA 0x05: `rh * 512`, `(t + 25) * 512`, big end first. From the
  HDC1080 if it has one, else the DHT22.
- eCO2 is an ESTIMATE from the VOCs it smells: there is no CO2 cell in it. The page's title says `eCO2 ESTIMATE`.
- The first 20 minutes are a warm-up and shown as one (`CCS_WARM_S 1200`).
- It holds SCL low while it thinks: the bit-banged bus allows a stretch of up to 25 ms.
- RAW_DATA's current and voltage are a clue to its supply, on the sensors page.
- Levels: eCO2 GOOD under 800, FAIR under 1200, POOR under 2000; TVOC 220, 660, 2200 (`../air-quality.md`).

## Traps

- It never has data: DATA_READY read from the status byte inside ALG_RESULT_DATA. Read STATUS on its own first. [measured]
