# ILI9486 on the Waveshare RPi LCD (A)

480x320, run in landscape, on a board that turns SPI into the panel's 16-bit bus with 74HC shift registers.
Raw `spi_master`, not esp_lcd. Sureness words as in [SKILL.md](../../SKILL.md).

## Where it is

- Waveshare RPi LCD (A) 3.5" on the OWLOS Air Quality board (classic ESP32) [measured with the Air Quality
  firmware: 110 ms a frame, 8 fps]. Flight Radar's build of it (`ili9486`) has not been seen running here
  [built]; its board.h still says "NOT run", a comment that came along from WiFi Radar. Board file:
  [ili9486](../../../esp32-boards/references/boards/ili9486.md).

## Settings that work

- MADCTL 0x28 (MV|BGR), found by a sweep in ViewOwl (an earlier firmware of ours) [measured].
- Inversion off on the (A) board [measured].
- 0x3A 0x55. 0x66 gives wrong colours on this bus: it is a 16-bit bus. The opposite of the ILI9488 on SPI.
- 20 MHz at most (the shift registers), the old firmware ran 10. 480x320 at 20 MHz is 123 ms a whole frame on
  the wire, 8 fps at most.
- A hardware reset pin here: low 10 ms, high, 120 ms before the first command.
- Strips of 8 rows. The 3.5" ST7796 went to 6 for the weather page; this one is not run with it yet [built].
- The backlight is wired to the power line: no pin, `disp_backlight` does nothing, a night mode can only darken
  the palette.
- Touch: XPT2046 on the same bus, CS 17, found by the Air Quality firmware [measured there]. Flight Radar's
  board.h says no touch, and its build leaves the touch's CS undriven, so it floats [reasoned from the code,
  left as it is]. BOOT is the whole interface there; the site sends the rest.
- No `remind()` on this path.

## Why it is different

Every command and parameter byte goes out as a 16-bit word with its own CS pulse; pixels are 16 bits anyway.
esp_lcd with 8-bit commands leaves this panel grey (ViewOwl found that the hard way): flat grey or white with
the backlight on, nothing ever drawn.

What each detail is for:

- `.spics_io_num = -1`: CS by hand, it has to go up after every padded byte and stay down through a whole strip
  of pixels.
- Commands and parameters by `spi_device_polling_transmit`, 2 bytes each. A window is 10 of them.
- 0x2C and a window for every strip. RAMWRC was not tried through the shift registers.

On `tx_data`: the real byte goes in `tx_data[1]`, `tx_data[0]` is 0x00. This runs on the glass [measured, Air
Quality]. The comment in the code says `[1]` leaves first (it lands in W0[15:8]); the file's header says "real
byte first, then 0x00". TFT_eSPI writes the same word for an RPi display, `(C)<<8` over 16 bits, and swaps its
pixels so that bits 7..0 of the register leave first, which would put 0x00 first and the byte second on the
wire [reasoned]. Nobody put a logic analyser on it. Either way, keep the byte in `[1]`.

The gamma values are TFT_eSPI's, through ViewOwl.

### The plain driver, Flight Radar

No DMA ping-pong: a strip goes out while the task waits. [built here; the Air Quality one below ran]

```c
#include "display.h"
#if DISP_ILI9486

#include "driver/gpio.h"
#include "driver/spi_master.h"
#include "esp_heap_caps.h"
#include "esp_log.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

static const char *TAG = "lcd";
static spi_device_handle_t s_spi;
static uint16_t *s_buf;
static int s_flip;

uint32_t disp_lost(void) { return 0; }
uint32_t disp_frame_ms(void) { return 0; }
void disp_frame_end(void) { }
void disp_full_next(void) { }
void disp_backlight(int percent) { (void)percent; }    // wired to power on this board

/* one padded byte. careful: with SPI_TRANS_USE_TXDATA tx_data[1] goes out FIRST
 * (it lands in W0[15:8]), so the real byte goes in [1] */
static void tx16(uint8_t b)
{
    spi_transaction_t t = { .length = 16, .flags = SPI_TRANS_USE_TXDATA };
    t.tx_data[0] = 0x00;
    t.tx_data[1] = b;
    gpio_set_level(PIN_LCD_CS, 0);
    spi_device_polling_transmit(s_spi, &t);
    gpio_set_level(PIN_LCD_CS, 1);
}

static void cmd(uint8_t c, const uint8_t *d, int n)
{
    gpio_set_level(PIN_LCD_DC, 0);
    tx16(c);
    gpio_set_level(PIN_LCD_DC, 1);
    for (int i = 0; i < n; i++) tx16(d[i]);
}

static void window(int x0, int y0, int x1, int y1)      // inclusive
{
    cmd(0x2A, (const uint8_t[]){ x0 >> 8, x0 & 255, x1 >> 8, x1 & 255 }, 4);
    cmd(0x2B, (const uint8_t[]){ y0 >> 8, y0 & 255, y1 >> 8, y1 & 255 }, 4);
}

void disp_init(void)
{
    gpio_config_t out = {
        .pin_bit_mask = (1ULL << PIN_LCD_CS) | (1ULL << PIN_LCD_DC) | (1ULL << PIN_LCD_RST),
        .mode = GPIO_MODE_OUTPUT,
    };
    ESP_ERROR_CHECK(gpio_config(&out));
    gpio_set_level(PIN_LCD_CS, 1);
    gpio_set_level(PIN_LCD_DC, 1);

    const size_t strip_bytes = GFX_W * DISP_STRIP * sizeof(uint16_t);
    spi_bus_config_t bus = {
        .sclk_io_num = PIN_LCD_SCLK,
        .mosi_io_num = PIN_LCD_MOSI,
        .miso_io_num = PIN_LCD_MISO,
        .quadwp_io_num = -1,
        .quadhd_io_num = -1,
        .max_transfer_sz = (int)strip_bytes,
    };
    ESP_ERROR_CHECK(spi_bus_initialize(SPI2_HOST, &bus, SPI_DMA_CH_AUTO));
    spi_device_interface_config_t dev = {
        .clock_speed_hz = LCD_SPI_HZ,
        .mode = 0,
        .spics_io_num = -1,                       // CS by hand, see tx16()
        .queue_size = 1,
    };
    ESP_ERROR_CHECK(spi_bus_add_device(SPI2_HOST, &dev, &s_spi));
    s_buf = heap_caps_malloc(strip_bytes, MALLOC_CAP_DMA | MALLOC_CAP_INTERNAL);
    if (!s_buf) ESP_LOGE(TAG, "no DMA memory for the strip");

    gpio_set_level(PIN_LCD_RST, 0);
    vTaskDelay(pdMS_TO_TICKS(10));
    gpio_set_level(PIN_LCD_RST, 1);
    vTaskDelay(pdMS_TO_TICKS(120));

    cmd(0x11, NULL, 0);                                   // sleep out
    vTaskDelay(pdMS_TO_TICKS(120));
    cmd(0x3A, (const uint8_t[]){ 0x55 }, 1);              // 16 bits a pixel, 0x66 gives wrong colours on these
    cmd(0xC2, (const uint8_t[]){ 0x44 }, 1);              // power control 3
    cmd(0xC5, (const uint8_t[]){ 0x00, 0x00, 0x00, 0x00 }, 4);   // VCOM
    cmd(0xE0, (const uint8_t[]){ 0x0F, 0x1F, 0x1C, 0x0C, 0x0F, 0x08, 0x48, 0x98, 0x37, 0x0A, 0x13, 0x04, 0x11, 0x0D, 0x00 }, 15);
    cmd(0xE1, (const uint8_t[]){ 0x0F, 0x32, 0x2E, 0x0B, 0x0D, 0x05, 0x47, 0x75, 0x37, 0x06, 0x10, 0x03, 0x24, 0x20, 0x00 }, 15);
    cmd(0x20, NULL, 0);                                   // inversion off, the (A) board wants it off
    cmd(0x36, (const uint8_t[]){ (uint8_t)(LCD_MADCTL ^ (s_flip ? 0xC0 : 0)) }, 1);
    cmd(0x29, NULL, 0);                                   // display on
    vTaskDelay(pdMS_TO_TICKS(150));
    ESP_LOGI(TAG, "ILI9486 %dx%d, SPI %d MHz, %d-row strips", GFX_W, GFX_H, LCD_SPI_HZ / 1000000, DISP_STRIP);
}

/* the picture turned 180 degrees (MY and MX), for a board mounted upside down. strips go out
 * from the task that calls this, so it never lands in the middle of one */
void disp_flip(int on)
{
    s_flip = on ? 1 : 0;
    if (s_spi) cmd(0x36, (const uint8_t[]){ (uint8_t)(LCD_MADCTL ^ (s_flip ? 0xC0 : 0)) }, 1);
}

void disp_strip(const canvas_t *cv)
{
    gfx_pack565(cv, s_buf);
    window(0, cv->y0, GFX_W - 1, cv->y0 + cv->h - 1);
    gpio_set_level(PIN_LCD_DC, 0);
    tx16(0x2C);                                           // memory write
    gpio_set_level(PIN_LCD_DC, 1);
    spi_transaction_t t = { .length = (size_t)GFX_W * cv->h * 16, .tx_buffer = s_buf };
    gpio_set_level(PIN_LCD_CS, 0);                        // the whole strip in one CS low
    spi_device_transmit(s_spi, &t);
    gpio_set_level(PIN_LCD_CS, 1);
}

#endif
```

### The driver that sends only what changed, Air Quality

A dashboard changes little from frame to frame and 20 MHz is 123 ms a whole frame. So every strip is
cut in columns of 32 px, each gets an FNV-1a checksum, and only runs of changed columns go out, as
their own window. Runs closer than 2 columns are merged, at most 4 a strip. A still screen sends
nothing. It relies on the ordered dither: a pixel that did not change packs to the same bits.
`disp_invalidate()` makes the next frame go out whole.

While one strip goes out by DMA the next is drawn: `spi_device_queue_trans`, CS taken down by hand
before and put up in `post_cb`, which has to be in IRAM. `disp_wait()` collects the transfer; the touch
on the same bus calls it before anything else, because the LCD's CS is down by hand during a strip
and a touch transfer then would talk to both.

With two painters (core 0 draws odd strips, core 1 even ones and sends all, in order): frame about
110 ms, 8 fps, drawing about 120 ms of CPU across both cores [measured].

```c
#include "display.h"
#include <string.h>

#include "driver/gpio.h"
#include "driver/spi_master.h"
#include "esp_heap_caps.h"
#include "esp_log.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

static const char *TAG = "lcd";

#define COL_W   32                         // checksum column, px
#define COLS    (GFX_W / COL_W)
#define STRIPS  ((GFX_H + DISP_STRIP - 1) / DISP_STRIP)

static spi_device_handle_t s_spi;
static uint16_t *s_buf[2];
static int       s_busy;
static spi_transaction_t s_t;
static uint32_t  s_sum[STRIPS][COLS];
static uint32_t  s_rows, s_px;

uint32_t disp_sent_rows(void) { return s_px / GFX_W; }   // full rows' worth of pixels that went out

static void IRAM_ATTR cs_up(spi_transaction_t *t)
{
    (void)t;
    gpio_set_level(PIN_LCD_CS, 1);
}

/* one padded byte. careful: with SPI_TRANS_USE_TXDATA tx_data[1] goes out FIRST
 * (it lands in W0[15:8]), so the real byte goes in [1] */
static void tx16(uint8_t b)
{
    spi_transaction_t t = { .length = 16, .flags = SPI_TRANS_USE_TXDATA };
    t.tx_data[0] = 0x00;
    t.tx_data[1] = b;
    gpio_set_level(PIN_LCD_CS, 0);
    spi_device_polling_transmit(s_spi, &t);
    gpio_set_level(PIN_LCD_CS, 1);
}

static void cmd(uint8_t c, const uint8_t *d, int n)
{
    gpio_set_level(PIN_LCD_DC, 0);
    tx16(c);
    gpio_set_level(PIN_LCD_DC, 1);
    for (int i = 0; i < n; i++) tx16(d[i]);
}

static void window(int x0, int y0, int x1, int y1)      // inclusive
{
    cmd(0x2A, (const uint8_t[]){ x0 >> 8, x0 & 255, x1 >> 8, x1 & 255 }, 4);
    cmd(0x2B, (const uint8_t[]){ y0 >> 8, y0 & 255, y1 >> 8, y1 & 255 }, 4);
}

// the strip before is still on its way: wait for it (the touch shares the bus, so it waits too)
void disp_wait(void)
{
    if (!s_busy) return;
    spi_transaction_t *done;
    spi_device_get_trans_result(s_spi, &done, portMAX_DELAY);
    s_busy = 0;
}

void disp_init(void)
{
    gpio_config_t out = {
        .pin_bit_mask = (1ULL << PIN_LCD_CS) | (1ULL << PIN_LCD_DC) | (1ULL << PIN_LCD_RST),
        .mode = GPIO_MODE_OUTPUT,
    };
    ESP_ERROR_CHECK(gpio_config(&out));
    gpio_set_level(PIN_LCD_CS, 1);
    gpio_set_level(PIN_LCD_DC, 1);

    const size_t strip_bytes = GFX_W * DISP_STRIP * sizeof(uint16_t);
    spi_bus_config_t bus = {
        .sclk_io_num = PIN_LCD_SCLK,
        .mosi_io_num = PIN_LCD_MOSI,
        .miso_io_num = PIN_LCD_MISO,
        .quadwp_io_num = -1,
        .quadhd_io_num = -1,
        .max_transfer_sz = (int)strip_bytes,
    };
    ESP_ERROR_CHECK(spi_bus_initialize(SPI2_HOST, &bus, SPI_DMA_CH_AUTO));
    spi_device_interface_config_t dev = {
        .clock_speed_hz = LCD_SPI_HZ,
        .mode = 0,
        .spics_io_num = -1,                       // CS by hand, see tx16()
        .queue_size = 2,
        .post_cb = cs_up,
    };
    ESP_ERROR_CHECK(spi_bus_add_device(SPI2_HOST, &dev, &s_spi));
    for (int i = 0; i < 2; i++) {
        s_buf[i] = heap_caps_malloc(strip_bytes, MALLOC_CAP_DMA | MALLOC_CAP_INTERNAL);
        if (!s_buf[i]) ESP_LOGE(TAG, "no DMA memory for the strips");
    }

    gpio_set_level(PIN_LCD_RST, 0);
    vTaskDelay(pdMS_TO_TICKS(10));
    gpio_set_level(PIN_LCD_RST, 1);
    vTaskDelay(pdMS_TO_TICKS(120));

    cmd(0x11, NULL, 0);                                   // sleep out
    vTaskDelay(pdMS_TO_TICKS(120));
    cmd(0x3A, (const uint8_t[]){ 0x55 }, 1);              // 16 bits a pixel, 0x66 gives wrong colours on these
    cmd(0xC2, (const uint8_t[]){ 0x44 }, 1);              // power control 3
    cmd(0xC5, (const uint8_t[]){ 0x00, 0x00, 0x00, 0x00 }, 4);   // VCOM
    cmd(0xE0, (const uint8_t[]){ 0x0F, 0x1F, 0x1C, 0x0C, 0x0F, 0x08, 0x48, 0x98, 0x37, 0x0A, 0x13, 0x04, 0x11, 0x0D, 0x00 }, 15);
    cmd(0xE1, (const uint8_t[]){ 0x0F, 0x32, 0x2E, 0x0B, 0x0D, 0x05, 0x47, 0x75, 0x37, 0x06, 0x10, 0x03, 0x24, 0x20, 0x00 }, 15);
    cmd(0x20, NULL, 0);                                   // inversion off, the (A) board wants it off
    cmd(0x36, (const uint8_t[]){ LCD_MADCTL }, 1);
    cmd(0x29, NULL, 0);                                   // display on
    vTaskDelay(pdMS_TO_TICKS(150));
    disp_invalidate();
    ESP_LOGI(TAG, "ILI9486 %dx%d, SPI %d MHz, %d-row strips, %d px columns", GFX_W, GFX_H, LCD_SPI_HZ / 1000000,
             DISP_STRIP, COL_W);
}

static uint8_t s_ok[STRIPS];                   // this strip's checksums are from the glass

void disp_invalidate(void) { memset(s_ok, 0, sizeof s_ok); }

uint16_t *disp_buffer(void)
{
    return heap_caps_malloc(GFX_W * DISP_STRIP * sizeof(uint16_t), MALLOC_CAP_DMA | MALLOC_CAP_INTERNAL);
}

/* any core: dither the strip to the panel's 565 and see which columns changed since it was last
 * packed. each strip has its own checksums, so two cores packing two strips never meet */
void disp_pack(const canvas_t *cv, packed_t *p)
{
    gfx_pack565(cv, p->px);
    p->y0 = cv->y0;
    p->h = cv->h;
    p->any = 0;
    const int si = cv->y0 / DISP_STRIP;
    for (int c = 0; c < COLS; c++) {
        uint32_t h = 2166136261u ^ (uint32_t)cv->h;
        for (int r = 0; r < cv->h; r++) {
            const uint32_t *q = (const uint32_t *)(p->px + r * GFX_W + c * COL_W);
            for (int i = 0; i < COL_W / 2; i++) h = (h ^ q[i]) * 16777619u;
        }
        p->changed[c] = !s_ok[si] || h != s_sum[si][c];
        p->any |= p->changed[c];
        s_sum[si][c] = h;
    }
    s_ok[si] = 1;
}

/* the screen task only, strips in any order: what changed goes to the glass. p->px is pulled
 * together in place, so it is used up; it is free again when the next disp_send returns */
void disp_send(packed_t *p)
{
    if (!p->any) return;                            // nothing changed in this strip
    /* the changed columns in runs: two HUDs side by side change on the left and on the right, the
     * gap between them did not. runs closer than 2 columns go out as one */
    int run0[4], run1[4], nr = 0;
    for (int c = 0; c < COLS; c++) {
        if (!p->changed[c]) continue;
        if (nr && c - run1[nr - 1] <= 2) run1[nr - 1] = c;
        else if (nr < 4) { run0[nr] = c; run1[nr] = c; nr++; }
        else run1[nr - 1] = c;
    }
    uint16_t *buf = p->px, *spare = s_buf[0];
    for (int k = 0; k < nr; k++) {
        const int x0 = run0[k] * COL_W, w = (run1[k] - run0[k] + 1) * COL_W;
        uint16_t *src;
        disp_wait();                                // nothing in flight: the spare and buf are free to change
        if (k < nr - 1 && spare) {                  // not the last run: copied out to the spare buffer
            for (int r = 0; r < p->h; r++) memcpy(spare + r * w, buf + r * GFX_W + x0, (size_t)w * 2);
            src = spare;
        } else {                                    // the last: pulled together in place
            if (w != GFX_W)
                for (int r = 0; r < p->h; r++) memmove(buf + r * w, buf + r * GFX_W + x0, (size_t)w * 2);
            src = buf;
        }
        window(x0, p->y0, x0 + w - 1, p->y0 + p->h - 1);
        gpio_set_level(PIN_LCD_DC, 0);
        tx16(0x2C);                                 // memory write
        gpio_set_level(PIN_LCD_DC, 1);
        memset(&s_t, 0, sizeof s_t);
        s_t.length = (size_t)w * p->h * 16;
        s_t.tx_buffer = src;
        gpio_set_level(PIN_LCD_CS, 0);              // the whole run in one CS low, cs_up() ends it
        if (spi_device_queue_trans(s_spi, &s_t, portMAX_DELAY) == ESP_OK) s_busy = 1;
        else gpio_set_level(PIN_LCD_CS, 1);
        s_px += (uint32_t)(w * p->h);
    }
    s_rows += (uint32_t)p->h;
}

void disp_strip(const canvas_t *cv)
{
    static packed_t p[2];
    static int cur;
    if (!p[0].px) { p[0].px = s_buf[1]; p[1].px = disp_buffer(); }
    if (!p[cur].px) return;
    disp_pack(cv, &p[cur]);
    disp_send(&p[cur]);
    cur ^= 1;
}
```
