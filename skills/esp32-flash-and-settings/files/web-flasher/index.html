ESP32 Web Flasher

Flash an ESP32 from this page, talk to it in a terminal, send it your WiFi. The firmware is built by GitHub Actions from its repository on every push and published here by GitHub Pages, with this page. The repository says how to make your own.

It needs Chrome or Edge on a computer: they have Web Serial, the way for a page to reach a USB port. Phones, Firefox and Safari don't.

1 Flash it

Plug the board in, press the button, pick its port. The page asks the chip what it is and takes the build for it: ESP32, ESP32-S2, S3, C3 or C6.

This browser can't flash: use Chrome or Edge on a computer. Flashing needs the page over https. Firmware @VERSION@
  • No port in the list? The cable may only charge, or the USB chip's driver is missing (CH340, CP210x).
  • Won't connect? Hold BOOT while you plug it in, or hold BOOT and press RST.
  • Erase asks whether to wipe the whole flash. Say yes the first time, no for an update: the WiFi it was given stays.
  • Close the flasher's window when it's done: one port, one program at a time.

2 Talk to it

A serial terminal in the page. It says what the board says, and what you type goes to the board. Try help and status.


    

      
      
    

  


  

    
3 Give it your WiFi

    
The same as typing ssid, pass and join in the terminal. It goes over
       the cable into the board's flash and nowhere else, the board never says the password back.

    

      
      
      
    

    
Once it joins, the terminal shows its address: open it in a browser on
       the same network and the board answers.
